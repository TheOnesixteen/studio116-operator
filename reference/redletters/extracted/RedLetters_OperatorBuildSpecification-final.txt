Key Status Rules
Public routes only show status Published with published_at less than or equal to now.
Draft, Hypothesis, Needs Verification, Reviewed, Scheduled, and Rejected return 404 publicly.
finding_number is assigned only at Scheduled or Published.
slug is stable after Published.
Reviewed requires title, hook, insight, sources, evidence_notes, confidence, safety_level, review fields, and verification where applicable.

10. Backup, Deploy, and Rollback
Backup Script
#!/bin/bash DB_PATH="${DATABASE_PATH}" BACKUP_DIR="/var/backups/redletters" TIMESTAMP=$(date +%Y%m%d_%H%M%S) ENV="${APP_ENV:-dev}" BACKUP_FILE="$BACKUP_DIR/redletters_${ENV}_${TIMESTAMP}.db"  mkdir -p $BACKUP_DIR sqlite3 $DB_PATH ".backup $BACKUP_FILE" echo "Backup: $BACKUP_FILE" ls -t $BACKUP_DIR/*.db | tail -n +15 | xargs -r rm echo "Rotation complete." 
Production cron: 0 2 * * * /opt/redletters/scripts/backup_db.sh >> /var/log/redletters/backup.log 2>&1
Restore test before launch: restore latest backup to /tmp/restore_test.db and compare row counts.
deploy-redletters always backs up database, pulls Git, installs requirements, runs migrations, restarts systemd, and checks health.
Rollback: stop service, checkout prior tag, restore pre-migration backup if schema changed, restart, verify /health.

13. AI Agent Rules
Never publish any finding automatically.
Never overwrite production database without a confirmed backup first.
Never commit secrets, API keys, or passwords.
Never change port 5016 without updating systemd, Caddy, docs, and tests.
Never introduce a frontend build system for MVP.
Never use a framework other than Flask without explicit approval.
Every route must be testable with curl.
Every database migration must be versioned and idempotent.
Every AI output must be written to generation_logs before parsing or transformation.
Every quantitative or pattern-based claim must have a verification run before Reviewed.
Every public finding must display confidence, safety level, source verses, evidence, and review status.
Every status change must write review_events.
Red (#C8342A) is used only for the wordmark, finding titles, and Phase 2 corpus words.
